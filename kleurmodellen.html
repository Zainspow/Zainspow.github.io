Kleurmodellen: RGB

Wat is RGB?

RGB betekent Rood, Groen en Blauw. Schermen mengen deze drie kleuren licht om alle andere kleuren te maken.

Kleuren mengen

Rood + groen = geel
Groen + blauw = cyaan
Rood + blauw = magenta
Rood + groen + blauw = wit

Getallen bij kleuren

Elke kleur heeft een getal van 0 tot 255. 0 is uit en 255 is helemaal aan.

Kleur Rood Groen Blauw
Rood 255 0 0
Groen 0 255 0
Blauw 0 0 255
Wit 255 255 255
